# Git workflow

Codex and Plurt Code must make all code changes on the existing `dev` branch. Before editing, switch to `dev` and pull the latest changes from `origin/dev`. Commit on `dev` and push directly to `origin/dev`. Do not create new branches.

# Communication

Use Roman Urdu written in the Latin alphabet for all user-facing communication in this repository. Do not use Hindi (Devanagari) script.
