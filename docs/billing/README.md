# Billing documentation

- FIELD-billing-spec.md: original supplied specification, preserved unchanged.
- implementationPlan.md: confirmed user override, implementation order and scope.
- BILLING_API.md: currently implemented routes and explicit API gaps.
- BILLING_OPERATIONS.md: migration, tax, webhook and personal-payment operations.
- PAYMENT_TERMS.md: machine-only billing, card or 30-day accounts, free
  periods, promo codes, reminders (API, config, screens, manual tests).

The personal payment implementation is not the whole specification. Refer to
the remaining-work section of implementationPlan.md before planning a release.
